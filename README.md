# The Walking Dead Fan Website

A multi-page fan website inspired by *The Walking Dead* universe, designed to provide an immersive browsing experience through character information, themed layouts, custom styling, authentication pages, and interactive navigation. This project demonstrates core frontend development skills using HTML and CSS while recreating the atmosphere of a post-apocalyptic survival world.

# Introduction

The Walking Dead Fan Website is a frontend web development project created to showcase information and content inspired by *The Walking Dead* franchise.

The project demonstrates the use of:

* HTML5
* CSS3
* Multi-page website architecture
* Navigation systems
* Form design
* User interface styling
* Responsive design concepts

The website recreates the visual atmosphere of the series while providing visitors with an easy-to-navigate informational platform.
